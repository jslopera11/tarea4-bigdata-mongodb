PASOS EN MONGODB COMPASS
1. Add new connection -> URI: mongodb://localhost:27017 -> Save & Connect.
2. Crear base de datos "internet_fijo_antioquia" con la colección "raw_accesos".
3. En cada colección: ADD DATA -> Import JSON or CSV file -> elegir el CSV -> Import.
     raw_accesos     <- accesos_internet_fijo_antioquia_2026T2.csv
     raw_municipios  <- municipios_antioquia_2026T2.csv
     raw_proveedores <- proveedores_internet_fijo_2026T2.csv
4. Abrir el shell (_MONGOSH, parte inferior de Compass) y pegar/ejecutar en orden:
     scripts/01_modelado.js       (crea municipios, proveedores y accesos + índices)
     scripts/02_crud.js           (inserción, selección, actualización, eliminación)
     scripts/03_filtros_join.js   (filtros, operadores y $lookup)
     scripts/04_agregaciones.js   (contar, sumar, promediar, $bucket)
   Recomendación: ejecutar cada consulta por separado y tomar pantallazo del código y del resultado.
